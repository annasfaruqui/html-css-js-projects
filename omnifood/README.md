# 🥗 Omnifood — Never Cook Again!

Omnifood is a landing page for an AI-powered healthy food subscription service tailored to personal tastes and nutritional needs. This project demonstrates responsive web design, mobile-first principles, modern CSS layout techniques (Flexbox & CSS Grid), and smooth JavaScript interactions.

## ✨ Features

- **Fully Responsive Across All Devices:** Carefully crafted breakpoints (covering 1344px desktop, 1200px landscape tablet, 944px tablet portrait, 704px small tablet, and 544px mobile phones).
- **Mobile Navigation Drawer:** Interactive hamburger menu icon with smooth toggle transition for mobile screens.
- **Sticky Navigation Header:** Dynamic sticky header triggered via the JavaScript Intersection Observer API when scrolling past the hero section.
- **Smooth Scrolling Navigation:** Cross-browser smooth scrolling for all internal anchor links, complete with a fallback polyfill for older Safari versions.
- **Rich Content Sections:**
  - **Hero Section:** Value proposition, social proof avatars, call-to-action buttons, and hero meal artwork.
  - **Featured In:** Logos of top publications (TechCrunch, Business Insider, NYT, Forbes).
  - **How It Works:** Step-by-step 3-part guide with floating mobile screen mockups.
  - **Meals & Diet Tags:** Meal cards with nutritional metadata (calories, NutriScore, ratings) and diet badges (Vegetarian, Vegan, Pescatarian, Keto, etc.).
  - **Testimonials & Photo Grid:** Customer quote cards paired with an appetizing 12-image food photography collage.
  - **Pricing & Features:** Tiered subscription cards (Starter vs. Complete with "Best Value" ribbon) and company feature perks.
  - **Lead Generation CTA Form:** Interactive customer sign-up form with custom styled select menus and input elements.
- **Web App Manifest & Favicons:** Progressive touch icons, favicon assets, and `manifest.webmanifest`.

## 🚀 How to Run Locally

This project is built with vanilla HTML, CSS, and JavaScript. No build step or package installation is required!

### Option 1: Live Server (Recommended)

1. Open the `omnifood` folder in **VS Code**.
2. Install the **Live Server** extension if you haven't already.
3. Right-click [`index.html`](index.html) and click **"Open with Live Server"**.
4. The site will open in your browser at `http://127.0.0.1:5500/index.html`.

### Option 2: Direct Browser Open

1. Navigate to the `omnifood` folder in your file explorer.
2. Double-click [`index.html`](index.html) (or drag & drop it into Chrome, Edge, Safari, or Firefox).
