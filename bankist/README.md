# 🏦 Bankist — When Banking Meets Minimalist

A sleek, minimalist marketing landing page for a fictional modern digital bank. This project demonstrates advanced DOM manipulation techniques, modern JavaScript UI patterns, and smooth micro-animations.

## ✨ Features

- **Modal Window:** Accessible "Open Account" modal popup triggered by multiple CTA buttons, closable via close button, background overlay click, or `Escape` key.
- **Smooth Page Navigation:** Smooth scrolling navigation links that smoothly transition to respective sections using `scrollIntoView({ behavior: 'smooth' })`.
- **Sticky Navigation Bar:** Efficient sticky header implementation powered by the modern **Intersection Observer API** without laggy window scroll listeners.
- **Tabbed Operations Component:** Dynamic tabbed component switching content panes with active state animations.
- **Lazy-Loading Images:** Low-resolution image placeholders that seamlessly transition to high-resolution assets as the user scrolls them into view, optimizing performance.
- **Testimonials Slider / Carousel:** Interactive testimonial slider featuring previous/next controls, keyboard navigation (left/right arrow keys), and interactive dot indicators.
- **Navigation Fade Animation:** Subtle opacity fading on unhovered sibling navigation links when hovering over the menu.

## 🚀 How to Run Locally

This is a pure static frontend project (HTML, CSS, and vanilla JS) with no dependencies or build steps required.

### Option 1: Live Server (Recommended)

1. Open the `bankist` folder in **VS Code**.
2. Install the **Live Server** extension (by Ritwick Dey) if you haven't already.
3. Right-click on [`index.html`](index.html) and select **"Open with Live Server"**.
4. The site will automatically launch in your default browser at `http://127.0.0.1:5500/index.html`.

### Option 2: Direct Browser Open

1. Simply navigate to the `bankist` folder in your file explorer.
2. Double-click [`index.html`](index.html) (or drag & drop it into any modern web browser like Chrome, Edge, or Firefox).
